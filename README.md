# Multi-Agent Brainstorming CLI (Watsap Hermes)

Sistem *multi-agent brainstorming* otonom berbasis CLI, Supabase, dan 9router.

## 🚀 Cara Menjalankan

1. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```

2. Jalankan agen Anda di terminal:
   ```bash
   python agent.py --name Noelle --owner Raken --url <SUPABASE_URL> --key <SUPABASE_KEY> --room usrc-brainstorm
   ```
